## 🚀 Sobre mí

Soy desarrollador web enfocado en el desarrollo **Full-Stack** con **React (JavaScript)** en el frontend y **Spring Boot + MySQL** en el backend. Me gusta llevar ideas desde el modelado de datos y la lógica de negocio hasta interfaces limpias, responsivas y listas para producción.

- 🧩 **Backend & Datos:** Diseño de APIs REST, persistencia con Spring Data JPA / Hibernate, modelado relacional en MySQL, validaciones de negocio y generación de reportes/documentos (como PDFs).
- 🎨 **Frontend & UI:** Interfaces dinámicas con React y JavaScript moderno, componentes reutilizables y maquetación responsiva con Bootstrap 5 y Material UI.
- ⚙️ **Despliegue & Entorno:** Trabajo habitual en Linux (Pop!_OS) y despliegue de servicios y aplicaciones web en la nube.
